## 💡 Notas
- **Formato:** PNG con fondo TRANSPARENTE (importante)
- **Tamaño:** 400x400 px o más
- **Estilo recomendado:** Personajes del Carnaval (marimonda, bailarines, máscaras)
- **Si no subes alguna**: la página automáticamente usa el emoji por defecto
