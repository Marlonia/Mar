# 📸 Guía de Imágenes - Carnaval BA Utah

Esta carpeta contiene todas las imágenes del sitio web. Cada subcarpeta tiene un propósito específico.

## 📁 Estructura de Carpetas

```
public/images/
├── hero/           → Imágenes del HERO de la página principal (fondo flotante)
├── about/          → Imagen de la sección "Sobre Nosotros" (Marimonda card)
├── dances/         → Imágenes para cada danza (Cumbia, Mapalé, Garabato, etc.)
├── coreografos/    → Fotos del equipo (Mayra, Marilyn, Karely, Adriana)
├── galeria/        → Fotos de eventos para la página /galeria
├── blog/           → Imágenes destacadas de los artículos del blog
├── tienda/         → Fotos de productos (trajes, máscaras, accesorios)
└── og/             → Imágenes Open Graph (cuando compartes en WhatsApp/Facebook)
```

---

## 🎯 ¿Dónde va cada imagen?

### `/hero/` - Imágenes flotantes del Home
Reemplazan los emojis 🎭 🎉 💃 🎶 que se ven flotando en el background del hero.

**Sube aquí estas imágenes con estos nombres exactos:**
- `floating-1.png` → Reemplaza el 🎭 (top-left, marimonda)
- `floating-2.png` → Reemplaza el 🎉 (top-right, fiesta)
- `floating-3.png` → Reemplaza el 💃 (bottom-left, bailarina)
- `floating-4.png` → Reemplaza el 🎶 (top-right-2, música)

**Tamaño recomendado:** 400x400 px, fondo transparente (PNG)

> 💡 Si no subes alguna, automáticamente usa el emoji.

## 📐 Formatos y Tamaños

| Tipo | Formato | Tamaño máximo |
|------|---------|---------------|
| Fotos | JPG | 500 KB |
| Iconos / Logos | PNG transparente | 200 KB |
| Productos | PNG/JPG | 300 KB |
| Hero / OG | JPG | 800 KB |

> 💡 **Consejo:** Comprime tus imágenes en https://tinypng.com antes de subir.

## 🔄 ¿Cómo se actualiza la web?

1. **Sube la imagen** a la carpeta correcta con el nombre exacto
2. **Hacé commit y push** desde GitHub o me avisas
3. **Vercel actualiza automáticamente** en 1-2 minutos
4. La imagen aparece en su lugar correspondiente

---

## ❓ Preguntas Frecuentes

### ¿Qué pasa si no subo una imagen?
La página muestra el **emoji por defecto** o un **placeholder**. Nunca se rompe el sitio.

### ¿Puedo cambiar los nombres?
Sí, pero tendrías que decirme para actualizar el código. Mejor usar los nombres sugeridos.

### ¿Puedo subir más imágenes que las listadas?
Sí, especialmente en `/galeria/` y `/blog/`. Solo dime el nombre y dónde quieres que aparezcan.
