# 📸 Galería de Eventos

Fotos de eventos, presentaciones y actuaciones para la página `/galeria`.

## 📤 Cómo subir

Puedes subir cualquier cantidad de fotos con cualquier nombre, pero te recomiendo nombres descriptivos:

```
ny-parade-2024-1.jpg
ny-parade-2024-2.jpg
karamba-2024.jpg
ensayo-2024.jpg
trajes-marimonda.jpg
```

## 📐 Especificaciones
- **Tamaño:** 1200x800 px o más
- **Formato:** JPG (recomendado)
- **Optimización:** Comprime en https://tinypng.com antes de subir

## 💡 Sugerencias
- Fotos del Hispanic Day Parade NY 2024
- Performances locales en Utah
- Ensayos generales
- Trajes y vestuarios
- Clases con estudiantes (con permiso)
- Eventos especiales

## 📝 Después de subir
Avísame qué fotos subiste y de qué evento son, para actualizar el código de la galería.
